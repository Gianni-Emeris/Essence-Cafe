## Project Overview
Essence Café is a restaurant website developed to showcase the café's menu, location, contact information, and customer reviews. The website provides an engaging user experience through responsive design, JavaScript functionality, and SEO best practices.

---

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- Visual Studio Code

---

## Website Pages
- **Home** (`index.html`)
- **About Us** (`about.html`)
- **Menu** (`menu.html`)
- **Contact & Location** (`contact&location.html`)
- **Reviews** (`review.html`)

---

## Key Features

### User Interface
- Responsive design for desktop, tablet, and mobile devices
- Consistent navigation across all pages
- Modern café-themed design using White, Black, and Copper Brown

### JavaScript Functionality
- Menu search functionality
- Dynamic content filtering
- Interactive image gallery
- Animated buttons and transitions

### Contact Features
- Contact information
- Trading hours
- Physical address
- Google Maps integration
- Social media links

---

## SEO Implementation
The website was optimized using:

- Relevant keywords
- Unique page titles
- Meta descriptions
- Structured headings (H1-H3)
- Image alt text
- Internal linking
- Mobile-friendly design
- `robots.txt` file
